# sutton-and-barto-from-scratch-5-mars-lander-from-flight-logs
Mission control wants a faster, fuel-saving autopilot for a Mars lander, but the only data is 500 flight logs from the cautious autopilot already in service. Build the lander and its exact values by dynamic programming, construct polynomial, Fourier, radial-basis and tile-coding features, and learn the cautious autopilot's landing probability…
